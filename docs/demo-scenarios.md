# 演示脚本 — 麦麦路上 McDrive Mate

> 三个端到端演示场景，覆盖项目核心价值的完整证明链：
> **时段感知 → 选店决策 → 预约下单 → 反悔机制**。
> 每个脚本可直接用于 WorkBuddy 实测、README 截图与演示视频。

通用前置：WorkBuddy 已配置 `mcd-mcp` Connector（见 README §3.2），麦当劳会员已登录。

## 场景 1：通勤早餐 · 预约单

**人设**：开车通勤族，路上只剩 15 分钟，想顺路拿早餐到公司吃。
**证明点**：时段感知（早餐档）、"比时间不比价格"、预约单缓冲、账单确认。

```text
👤 8:05 从家出发，走XX路到公司，路上帮我安排个早餐，到了直接拿

🤖 早上好。现在是 8:05，早餐档（供应到 10:30）。
   [query-nearby-stores]
   你沿途有 3 家门店，按预计总耗时排序：

   🚗 麦麦路上 · 选店决策（预计 8:20 到达XX路）
   | 方案 | 门店 | 方式 | 预计总耗时 | 说明 |
   |---|---|---|---|---|
   | ✅ 推荐 | XX路店 | 到店取（预约 8:25） | ~5 分钟 | 预约单，到达即取 |
   | 备选 | YY街店 | 得来速 | ~8 分钟 | 顺路但车道需排队 |
   | 备选 | 麦乐送到公司 | 外送 | ~25 分钟 | 早高峰配送较慢 |

   推荐方案 A：预约单让你到达时刚好出餐。去这家吗？

👤 行，套餐来个吉士蛋麦满分套餐，咖啡换热美式

🤖 [query-meals → calculate-price]
   🧾 待确认订单
   🏪 XX路店（到店取）
   ⏰ 预约取餐：8:25（已含 5 分钟缓冲）
   🍔 吉士蛋麦满分套餐（咖啡→热美式）×1  ¥xx.x
   🎟 优惠：早餐券 -¥x.x
   ────────
   💰 应付：¥xx.x

   确认后我马上下单，回复"确认"即可。

👤 确认

🤖 [create-order] 已下单 ✅ 支付链接：…
   预约取餐 8:25，到店取餐柜扫码即可。
   改主意随时说"取消订单"。
```

## 场景 2：得来速 · 深夜热食

**人设**：夜班族 23:10 下班，想吃口热的再回家。
**证明点**：深夜营业门店筛查（不假设 24h 店存在）、时段心智（晚间小食）、安全话术。

```text
👤 刚下夜班，想吃点热的再回家

🤖 [now-time-info → query-nearby-stores]
   现在 23:10，附近还在营业的有 2 家：
   - A 家（24h 营业）✅ 推荐 · 得来速 · 预计 ~8 分钟
   - B 家（24:00 关门）· 得来速 · 预计 ~7 分钟，但请留意 24:00 前到达

   深夜档有：麦麦鸡×5、香芋派、麦乐鸡酱烤版、热可可…
   想来点哪个？还是看看你上次点的老样子？

👤 去A家，麦麦鸡加个派，得来速拿

🤖 [calculate-price]
   🧾 待确认订单
   🏪 A 家（得来速）
   🍔 麦麦鸡×5 ¥xx.x ｜ 香芋派 ×1 ¥x.x
   💰 应付：¥xx.x（本店无可用券）
   确认后下单。另外——下夜班辛苦了，建议到店后再确认支付，安全第一。

👤 好，确认

🤖 [create-order] 已下单 ✅ 支付链接：…
   得来速报取餐码即可，改主意随时说"取消订单"。
```

## 场景 3：反悔与改约

**人设**：已在场景 1 下过预约单，路上突然堵车。
**证明点**：取消零追问、"改单=取消重下"策略、主动给出更优解。

```text
👤 堵死了，8:25 赶不到了，取消

🤖 [cancel-order] 已取消 ✅ 随时重新下单。
   现在看路况大概要 8:45 才能过XX路，要不要我改约 8:50 的预约单，
   菜单不变？

👤 好

🤖 [calculate-price → create-order]
   已重新下单 ✅ 预约取餐 8:50（已含 5 分钟缓冲），商品和价格不变。
   改主意随时说"取消订单"。
```
